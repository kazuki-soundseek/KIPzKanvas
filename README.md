# KIPzKanvas — 中継スイッチャー ⇄ 現地のカンペ共有

東京のスイッチャー席から、現地の実況・リポーターへ「VTRふり」「CM入ります」などの
指示を大きな文字で送るためのアプリです。ブラウザで開くだけで動くので、
タブレット・スマホ・PCへのアプリのインストールは不要です。

## できること

- **指示の送信**（東京側）: 定型ボタンを1タップ、または自由入力。色分けは 通常／注意（橙）／緊急（赤）
- **マーカー（蛍光ペン）**: 自由入力で文字を選んで「🖊 マーカー」を押すと、その部分が黄色マーカーで強調される。
  送信済みの指示も「🖊 マーカー編集」でリアルタイムに書き換え可能。
  定型ボタンでは `==この部分==` のように `==` で囲むとマーカーになる
- **画像の送信**: 「📷 画像」から選ぶだけ。自動で軽いサイズ（長辺1400px）に変換して送られる
- **URLの送信**: URLを貼って送ると、現地側には「リンクを開く」の大きなボタンで表示される
- **大文字表示**（現地側）: 届いた指示が画面いっぱいの大きさで自動表示。チャイム音・振動・画面の点滅つき
- **受領スタンプ**（現地側）: 「👍OK・了解」「✋できない」を1タップ。東京側は誰が確認したか一覧で見え、15秒たっても誰も押さないと「⚠未確認」と表示
- **カウントダウン**: 東京側が10秒/5秒/3秒を選ぶと、全員の画面に 5→4→3→2→1→**GO** が全画面で出る（ピッ音つき、途中中止可）
- **取消・再送**: 送った指示の取り消し、履歴からのワンタップ再送
- **接続の見張り**: 相手が落ちたら「⚠現地が未接続」と警告。通信が切れたら赤いバナーで「再接続中」
- **その他**: 画面スリープ防止（対応端末）、通知音の入切、文字サイズ調整、定型ボタンの文言編集（全員に同期）

## 使い方（毎回の流れ）

1. 全員が同じURLを開き、**同じ部屋コード**を入れる（例: `race-0802`）
2. 東京の人は「東京」、現地の人は「現地」を選んで入室
3. 東京側の「現地用リンク」ボタンでQRコードを出せば、現地の人はカメラで読むだけで入れます

> 部屋コードがパスワード代わりです。`race1` のような推測されやすいものより、
> `kipz-0802-xR7` のように日付や適当な文字を足したものにしてください。

## いますぐ試す（このPCだけ／同じWi-Fi内）

PowerShell でこのフォルダを開いて:

```
node dev-server.js
```

と打つと起動し、アドレスが表示されます。

- このPCでは `http://localhost:8790` を開く
- 同じWi-Fiにつながったタブレット・スマホからは、起動時に表示される `http://192.168.〜:8790` を開く
- ブラウザの窓を2つ並べて「東京」「現地」でそれぞれ入室すれば、1台でも動作確認できます

初回はWindowsのファイアウォールの許可画面が出ることがあります。「アクセスを許可する」を押してください。

※iPhoneのSafariで「HTTPS-Only」のエラーが出る場合は、iPhoneの「設定」→「Safari」→「詳細」→
「HTTPSを常に使用」を一時的にオフにしてください（下の本番セットアップ後は不要になります）。

**このモードは同じネットワーク内限定です。** 東京⇔現地のように離れた場所で使うには、次の本番セットアップをします。

## 本番セットアップ（インターネット越しで使う・無料）

通信の中継役として Google の無料サービス **Firebase** を使います。
かかる時間は30分ほど、クレジットカード登録は不要で、この用途なら無料枠に収まります。
やることは「①Googleに部屋を借りる → ②アプリに部屋の住所を書く → ③アプリをネット上に置く」の3つです。

### ① Firebaseのプロジェクトを作る

1. https://console.firebase.google.com をGoogleアカウントで開く
2. 「プロジェクトを作成」→ 名前は `kipz-kanvas` など → Googleアナリティクスは**無効でOK** → 作成
3. 左メニュー「構築」→「**Realtime Database**」→「データベースを作成」
   - ロケーションは **Singapore (asia-southeast1)** を選ぶ（日本から一番近い）
   - セキュリティルールはどちらを選んでもOK（後の手順で正しいものに上書きされます）

### ② アプリに設定を貼る

1. Firebaseの画面左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」→ **`</>`（ウェブ）** を押す
2. ニックネームは `kanvas` など → 「アプリを登録」
3. 画面に `const firebaseConfig = { apiKey: ... }` という設定が出るので、`{ }` の中身をコピー
4. このフォルダの **`firebase-config.js`** を開き、説明に沿って `null` を貼り替えて保存

### ③ アプリをネット上に置く（Firebase Hosting）

PowerShellで:

```
npm install -g firebase-tools
```

```
firebase login
```

（ブラウザが開くのでGoogleアカウントで許可）

続けて、このフォルダで:

```
firebase deploy --project あなたのプロジェクトID
```

プロジェクトIDは「プロジェクトの設定」画面に書いてあります（例: `kipz-kanvas`）。
成功すると `https://あなたのプロジェクトID.web.app` というURLが表示されます。**これが本番URLです。**
東京も現地も、以後このURLを開くだけです（dev-server.js の起動は不要になります）。

- ボタンの文言などを直したら、もう一度 `firebase deploy --project 〜` を打てば反映されます
- データベースの読み書きルール（database.rules.json）もdeployで一緒に反映されます

### 料金と安全性について

- 無料枠: 同時接続100台・転送10GB/月まで無料。文字は余裕、画像も1枚300KB程度に自動圧縮されるので通常の使い方なら収まります
- 部屋コードを知らない人はまず辿り着けませんが、鍵付きの仕組みではないので、
  **放送前の機密情報などは書かない・映さない**運用にしてください

## 番組での使い方のコツ

- **Zoomと同時に見る（1台で）**
  - iPad: Zoomアプリを開いた状態で、画面下から出るDockからSafari（このアプリ）を長押し→画面の右端へドラッグすると左右分割（Split View）になります
  - Android: 「最近使ったアプリ」一覧でアプリのアイコンをタップ→「分割画面」
  - このアプリは半分幅でも文字が自動で最大サイズに調整されます
- **2台に分ける**のも確実です（Zoom用タブレット＋カンペ用スマホ など）
- **音**: ブラウザの仕様上、入室ボタンを押した後でないと音が鳴りません。入室後に東京側からテスト送信して、現地で音量を確認してください
- **スリープ**: アプリ側でも防止しますが、念のため端末の設定でも画面消灯を「しない」にしておくと安心です
- **ホーム画面に追加**: SafariやChromeの「ホーム画面に追加」をすると、全画面のアプリのように使えます

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 音が鳴らない | 入室し直す／右上の🔔がONか確認／端末のマナーモード解除 |
| 「再接続中」が消えない | 電波・Wi-Fiを確認。テストモードの場合はPCの `node dev-server.js` が動いているか確認 |
| タブレットから開けない（テストモード） | PCと同じWi-Fiか確認。Windowsファイアウォールの許可を確認。iPhoneは上記のHTTPS-Only設定を確認 |
| 相手が「未接続」のまま | 相手側がまだ入室していないか、部屋コードが違う |
| 画像が表示されない | 「履歴を全消去」した後の再送は画像が消えているため送り直す |
| 画面が暗くなって消える | 端末の画面消灯設定を「しない」に |

## ファイル構成（変更したい人向け）

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面の見た目（ホワイトテーマ） |
| `js/app.js` | 画面の動き（表示・マーカー・画像・音・カウントなど） |
| `js/store.js` | 部屋の状態（指示・参加者）の持ち方 |
| `js/transport.js` | 通信（テストモード／Firebase の切り替え、画像の受け渡し） |
| `dev-server.js` | テストモード用の簡易サーバー（画像の中継つき） |
| `firebase-config.js` | 本番用Firebase設定の貼り付け先 |
| `firebase.json` / `database.rules.json` | Firebase公開用の設定 |

定型ボタンの初期の文言は `js/store.js` の一番上にあります（アプリ内の「設定」からも変更できます）。
